System Architecture
===================

This document describes the structure of the robot arm. Most of its content comes from the
SysML v2 model in ``model/``: the needs generated from the model and the diagrams in ``views/``.

.. note::

   This is a skeleton. The content comes in Phase 5.

What will go here
-----------------

* the system context: actors, system ports and the interfaces between the domains
  (electrical, mechanical, software);
* the functional architecture: the functions and the use cases they realize;
* the logical architecture: the logical elements and the functions they realize;
* the product architecture for all members of the product line, with its variation points;
* the feature model and the configurations (prototype and product), with one page per
  configuration;
* the diagrams (views) of the model.

Model elements with trace links become needs. They are imported here from the generated file:

.. needimport:: /generated/model-needs.json
