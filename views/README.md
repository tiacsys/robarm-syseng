# Views

One `<view>.drawio.svg` per view defined in `model/views.sysml` (D94, D96). The files are
written by `curatrix views build robarm-syseng` and checked by `curatrix check` (CK-D3).
Each file is an SVG picture with the editable drawio diagram inside. You may open one in drawio
(`curatrix launch drawio`) to tidy the layout; run `curatrix views normalize <file>` afterwards.
